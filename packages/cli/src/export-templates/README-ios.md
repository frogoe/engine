# iOS — finishing guide (frogoe export ios)

The project under `src-tauri/gen/apple/` is a real Xcode project (generated
via XcodeGen from `project.yml`). Building needs no signing for the
**simulator**; the App Store needs your Apple Developer account.

## Simulator (no account needed)

```bash
frogoe run ios          # from the game folder: dev server + simulator, hot reload
bun tauri ios dev       # or drive it yourself from export/
```

## Device + App Store (agent-completes — your credentials)

1. Open `src-tauri/gen/apple/*.xcodeproj` in Xcode once → select the project
   target → **Signing & Capabilities** → pick your Team. (Or export
   `APPLE_DEVELOPMENT_TEAM` and set it in `project.yml`.)
2. Build an IPA:

```bash
bun tauri ios build     # produces the IPA under src-tauri/gen/apple/build
```

3. Upload via **Transporter** or `xcrun altool`, then App Store Connect.

The bundle identifier is `frogoe.json`'s `appId` — it must be registered as
an App ID in your Apple Developer account.

## What lives where

- `src-tauri/gen/apple/` — regenerated by `frogoe export ios --force`;
  your plist/entitlement edits survive normal re-exports (init is skipped
  when the dir exists)
- `src-tauri/gen/apple/Assets.xcassets/AppIcon.appiconset/` — all 19 sizes,
  generated from `assets/icon.js` by `tauri icon`
- The game artifact is embedded at `web/index.html` — `tauri ios build`
  bundles it into the app with zero network at runtime
