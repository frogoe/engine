# Android — finishing guide (frogoe export android)

The project under `src-tauri/gen/android/` is a standard Gradle project.
Debug builds sign with an auto-generated debug keystore; Play Store needs
your upload key.

## Prerequisites

- Android SDK (`ANDROID_HOME`, or Android Studio's default
  `~/Library/Android/sdk`) with platform-tools
- Java (Android Studio bundles one; otherwise a JDK 17+)

`frogoe run android` checks these first and teaches the fix when missing.

## Emulator / device (no account needed)

```bash
frogoe run android       # from the game folder: dev server + app, hot reload
```

Boot an emulator or plug a device first (`adb devices` must list one) —
the devUrl is chosen per target (emulator loopback vs LAN for a device).

## Play Store (agent-completes — your credentials)

1. Create an upload keystore once:

```bash
keytool -genkey -v -keystore upload.jks -alias upload -keyalg RSA -validity 10000
```

2. Point Gradle at it via `src-tauri/gen/android/keystore.properties`
   (gitignore it — it is yours, never frogoe's):

```properties
storeFile=/absolute/path/to/upload.jks
storePassword=…
keyAlias=upload
keyPassword=…
```

3. Build the bundle:

```bash
bun tauri android build     # produces .aab under src-tauri/gen/android
```

4. Upload the .aab to Play Console (internal testing track first).

The applicationId is `frogoe.json`'s `appId`.

## What lives where

- `src-tauri/gen/android/` — regenerated by `frogoe export android --force`;
  normal re-exports skip init and keep your edits (keystore wiring, manifest
  tweaks)
- Launcher icons (all densities + adaptive) regenerate via `tauri icon`
- The game artifact is embedded at `web/index.html` — zero network at runtime
