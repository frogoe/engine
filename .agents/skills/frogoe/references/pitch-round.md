# Pitch round — five divergent game concepts

Unformed requests only ("make me a fun game", "something about space"). Formed requests and explicit genre picks go straight to the must-haves.

## Sampling gate

Ask internally 4 questions before generating concepts:

1. What does the verb look like as a one-second loop?
2. What emotion does the screen need to carry?
3. What is the play field — tight column or open canvas?
4. What is the anti-pattern to invert (the generic game this must not be)?

Then generate 5 concepts from 5 genuinely different paths (subject world / emotion / audience / inverted anti-pattern / unusual format). Enforce tail distribution: at least 2 concepts with probability below 0.10 (genuinely surprising), and a silhouette check (no two concepts share the same core loop shape). Probabilities are never shown to the user.

## Presentation

3 lines per pitch: concept (one sentence), visual world (palette + typography hint), hook (why this game is memorable). Name 1-2 capabilities from `capability-menu.md` in plain language. Show all 5 before recommending one. Mix, combine, or redirect are valid answers. On an autonomous run ("just build it", "surprise me"), the same gate runs internally and the heads-up names the direction chosen and the typical one left behind.

## Decision map for "I don't know games"

If the user says they do not know what game to make, do not pitch 5 yet — give 2-3 decision surfaces with 2-4 options each, defaults marked:

- **Verb:** tap / hold / steer / aim (recommend one with reason)
- **Mood:** urgent / cozy / arcade / minimal (pick from palettes)
- **Palette:** 2-3 named palettes by eye (open each `palettes.md` preset mentally, but show as words)

Collect those before entering the 5-concept round. This grounds the pitch in the user's taste instead of pure invention.
